## 4. Data sources

- Usage limits, model catalog and statistics are read from the local **omp** CLI
  (`omp usage --json`, `omp models --json`, `omp stats --json`, `omp usage --history`). All dollar
  amounts are computed by omp from its model catalog's API list prices — the **API-equivalent cost**
  of the usage, not a subscription bill. This plugin performs no network requests of its own.
- Tern and omp are products of Stencil (<https://stencil.so>). This plugin is an independent
  community work and is not affiliated with or endorsed by Stencil.
